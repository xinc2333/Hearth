## 模型连接

在「设置 → 模型连接」里添加。Hearth 支持所有 OpenAI 兼容接口，包括 OpenAI、DeepSeek、OpenRouter、各类中转，以及 Gemini 和 Claude 的兼容地址。

- **接口地址**：一般以 `/v1` 结尾，例如 `https://api.deepseek.com/v1`。
- **API 密钥**：只保存在本机。
- **模型**：点开后会列出接口提供的全部模型，可以搜索，选中立即生效。列表里没有的模型，可以直接输入名称。

可以添加多个连接，点「设为当前」切换。「测试连接」会发一条简短的消息，确认能收到回复。

## 导入

把文件拖进窗口，或点左上角的「导入」：

| 文件 | 导入为 |
| --- | --- |
| 角色卡（PNG 或 JSON，V1～V3） | 角色。卡里自带的世界书会一起导入并绑定 |
| 酒馆世界书（JSON） | 世界书，在角色的「世界书」页里绑定 |

预设在「设置 → 预设」里导入，见[预设](#预设)。

导入的原始文件会备份在数据目录的 `imports/` 里。

## 预设

预设是全局的，所有角色和对话共用当前预设。预设只在「设置 → 预设」里管理。

- **导入**：点「导入预设」，选择酒馆导出的 Chat Completion 预设（JSON）。导入后自动设为当前预设。
- **切换**：从列表里选择预设，点「设为当前预设」。
- **开关条目**：和酒馆一样，改动立即生效。点开条目可以查看和编辑内容。
- **分组和单选**：带菜单标记的预设（如 Meowssiah）会按分组显示；标了「单选」的同组条目只能开一个。
- **适配过的预设**：预设可以在条目里声明支持聊天模式、深度思考和纸条，也可以带上跑团条目。导入适配过的预设后，输入框旁会出现对应的开关。适配方法见[预设适配](presets.md)。

## 界面

- **左侧**：角色和对话列表。按 `Ctrl+B` 可以收起。
- **中间**：对话。
  - 鼠标移到消息上，可以复制、编辑、删除，或者从这条回复创建分支。分支是一个新对话，原对话不受影响。
  - 最后一条回复可以切换版本、重新生成或继续写。
- **面板**：点右上角的「面板」或按 `Ctrl+I` 打开，拖动左边缘可以调整宽度。

| 面板页 | 内容 |
| --- | --- |
| 界面 | 角色卡自带的界面，例如状态栏侧边栏、小手机、资源库（只在角色卡带脚本时出现）。卡第一次显示出界面时，面板会自动打开到这一页 |
| 提示词 | 上一次或下一次请求的完整内容，每段都标明来源。角色卡自己向模型发的请求也在这里 |
| 变量 | MVU 变量、对话变量和最近一轮的变化 |
| 跑团 | 属性、状态和态度（启用跑团时） |
| 角色卡、世界书 | 直接编辑。长文本可以放大编辑 |
| 历史 | 所有修改，可以逐条撤销 |

关闭窗口时，Hearth 会留在屏幕右下角的通知区域继续运行，正在生成的回复不会中断。单击通知区域里的图标，或者再打开一次 Hearth，都可以回到窗口。要退出，右键点图标，选「退出 Hearth」。

## 回复模式和开关

输入框左下角可以切换三种模式：

| 模式 | 用途 |
| --- | --- |
| 剧场 | 正常写剧情 |
| 聊天 | 暂停剧情，直接和 AI 聊天，例如讨论剧情走向。回复一次后自动回到剧场 |
| 编辑 | 和 AI 讨论并修改角色卡和世界书，见 [AI 改卡](#ai-改卡) |

当前预设支持时，输入框旁还有这些开关：

- **深度思考**：回复前先按预设的要求深入思考，回复会慢一些。
- **纸条**：写给 AI 的场外指示，例如「这一轮多写环境描写」。随下一条回复发送，送达后自动清空。
- **检定绝对通过**：跑团用，见[跑团](#跑团)。

预设没有声明支持聊天模式、深度思考或纸条时，对应的开关不会出现。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+K` | 快速查找角色、对话和功能 |
| `Ctrl+B` | 显示或收起侧栏 |
| `Ctrl+I` | 打开或关闭面板 |
| `←` `→` | 输入框为空时，切换最后一条回复的版本；在最后一个版本按 `→` 会生成新版本 |
| `Esc` | 停止生成；关闭弹窗 |
| `Enter` / `Shift+Enter` | 发送 / 换行 |
| `Ctrl+Enter` | 保存正在编辑的消息 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 恢复界面 |
| `F5` | 重新载入界面 |

## 阅读设置

点对话右上角的「Aa」，可以调整字体、字号、行距、栏宽、段首缩进、两端对齐和对话着色。「自定义」字体可以填写电脑上已安装的任意字体，例如霞鹜文楷。

回复生成时，画面默认停在回复开头，便于从第一行读起。如果想一直跟随最新的文字，在阅读设置里打开「生成时自动滚到最新文字」。

## AI 改卡

把输入框左下角从「剧场」切换到「编辑」，然后直接说想怎么改。例如：「把她的年龄改成二十八岁」「根据刚才的剧情，给书摊老板加一个世界书条目」。

- AI 会说明打算怎么改，然后保存。消息下方列出每一处改动：
  - 「查看改动」可以对照前后内容。
  - 「撤销」会撤销这一轮的全部修改。
- 只改你要求的部分，其余文字保持不变，导出给酒馆也照常使用。
- 以下条目默认只读，避免改坏变量和章节控制：
  - 变量初始化和变量规则的条目
  - 带模板代码的条目
  - 和其他角色共用的世界书

  需要修改条目时，在世界书条目里打开「允许 AI 修改」。共用的世界书始终只读。
- 编辑模式里的对话不会进入剧情。切回「剧场」就继续故事。

## 跑团

跑团让剧情有掷骰检定和角色属性，别人对主角的态度随事件变化。数值只是让剧情更真实的依据，一切从主角的视角出发。完整规则见[跑团设计](tabletop.md)。

### 准备

每张角色卡只需要做一次：

1. **添加预设条目**：适配过跑团的预设自带跑团条目。其他预设在面板的「跑团」页点「加到当前预设」，预设末尾会多出四条「跑团·……」条目，可以在预设里查看和修改。
2. **数据化适配**：切换到「编辑」模式，点输入框下方的「数据化适配」。
   - AI 会通读角色卡和世界书，以「普通成年男性 = 100」为基准，给主角和主要角色的属性打分，写出他们对主角的初始态度，以及他们彼此之间的关系。
   - 每个数值都附有原文依据。
   - 可以接着让 AI 调整，例如「她的力量太高了」，也可以撤销。

### 每一轮

1. **裁定**：模型判断这一轮哪些行动结果不确定，并写好大成功、成功、失败、大失败四种结果。Hearth 掷骰，选出其中一种。
2. **叙述**：模型按掷中的结果写正文。
3. **结算**：正文出现后，Hearth 在后台再问一次模型：在场的每个角色对主角的态度有没有变化，有没有受伤或恢复，有没有新角色。Hearth 按规则更新数据。

- 回复上方显示这一轮的检定，点开可以看理由和计算过程。主角察觉不到的「暗骰」默认收起。
- 回复下方显示结算的结果：主角自己的变化直接显示，例如「新状态：左臂刀伤」；别人的态度只显示「林晚记住了这件事」，点一下才看得到具体变化。结算没有完成时，可以点「重新结算」。
- 结算在后台进行，不用等。如果结算还没完成就发了下一条，会先等它做完。
- 换一版回复只重写正文，骰子不变，新版本单独结算。修改自己的消息后重新生成，会重新裁定。
- 输入框旁的「检定绝对通过」：这一轮不掷骰，主角的行动全部顺利，发送后自动关闭。
- 聊天模式下不跑跑团。
- 「跑团」页按主角的视角显示数据。其他角色只显示大致水平，他们对你的态度和彼此之间的关系默认隐藏，点「揭开」查看。数值可以直接修改。
- 每一轮会多两次请求（裁定和结算），回复出现前要多等几秒。
- 发给模型的跑团数据只有在场角色的完整数值，其他角色只带名字和对你的态度，再次出场时自动带上。剧情里遇到的人越来越多，每轮的请求也不会跟着明显变长。

### 态度

- 只记录别人对主角的态度，分亲近、怨恨、信任、敬重、畏惧、吸引六条线，另有熟悉度。主角自己的感情由你决定，不记录。
- 角色之间的关系用几个字记录，例如「表面客气，暗中提防」，发生事件时更新。
- 所有变化都由事件引起，每一条都记下缘由。

之前用旧版跑团条目的预设，面板的「跑团」页会提示「更新跑团条目」。更新后改为每轮单独结算。

## 插件

在「设置 → 插件」里可以开关插件、检查更新，也可以粘贴 GitHub 链接安装新插件。Hearth 自带三个插件：

| 插件 | 作用 |
| --- | --- |
| 提示词模板 | 运行预设、角色卡和世界书里的 EJS 模板，兼容 [ST-Prompt-Template](https://github.com/zonde306/ST-Prompt-Template) |
| 酒馆助手 | 运行角色卡的状态栏、开局面板等界面和卡自带的脚本，处理 MVU 变量，适配 SPreset 类预设，兼容 [JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) |
| 跑团 | 掷骰检定、角色属性，以及别人对主角的态度和角色之间的关系 |

- 插件会自动更新：启动后检查一次，之后每 6 小时检查一次。每个插件都可以单独关闭自动更新。
- 想马上更新时，点「设置 → 阅读与外观」里版本号旁边的「检查更新」，会同时检查 Hearth 和所有插件。
- 关闭插件后，角色卡和预设里的相关内容会原样保留，只是不再处理。
- 关闭「跑团」时，要同时关闭预设里的「跑团·……」条目，否则它们会作为普通条目发给模型。

## 网络代理

Hearth 和浏览器一样使用系统代理。在 V2Ray、Clash 等工具里开启「系统代理」后，模型请求和自动更新都会经过代理，不需要另外设置。

如果不想修改系统代理，可以设置环境变量 `HTTPS_PROXY`，例如 `http://127.0.0.1:10808`。Hearth 启动时会读取它。

## 数据与运行记录

- **数据目录**：所有数据都在 `%APPDATA%\Hearth\data`，在资源管理器的地址栏输入 `%APPDATA%\Hearth` 就能打开。
  - 每个角色、世界书、预设和对话各是一个文件。
  - 备份时复制整个 `data` 文件夹即可。
  - 更新和卸载都不会删除数据。
- **运行记录**：在 `%APPDATA%\Hearth\logs\hearth.log`。反馈问题时请附上这个文件。

## 兼容情况

| 内容 | 状态 |
| --- | --- |
| 角色卡：字段、备选开场白、角色备注 | 支持 |
| 预设：条目顺序、开关、注入深度和角色、主提示词和后置指令覆盖 | 支持，组装规则与酒馆一致 |
| 世界书：关键词逻辑、扫描深度、递归、分组、概率、预算、粘滞和冷却、全部插入位置 | 支持 |
| 宏：`{{char}}`、`{{user}}`、变量宏、`{{random}}`、`{{roll}}` 等 | 支持常用宏 |
| 正则脚本 | 支持 |
| 角色卡界面（状态栏、开局面板等） | 在隔离环境中运行，提供酒馆助手的常用接口：读写变量、楼层和这个角色自己的世界书。界面做的修改记在修改历史里，可以撤销 |
| MVU 变量 | 支持。角色卡定义了变量结构时按结构检查；模型漏写时自动补全 |
| EJS 提示词模板 | 支持常用写法，包括 `@@preprocessing` 条目 |
| SPreset 类预设（如 Meowssiah） | 支持，发给模型的内容与酒馆一致；回复模式、深度思考和纸条在输入框旁 |
| 酒馆助手脚本 | 角色卡的脚本在隔离环境中运行，界面显示在面板的「界面」页，可以调用模型、在生成前加入提示词。MVU 和 SPreset 的脚本由「酒馆助手」插件提供同样的功能。预设里的脚本不运行 |
| STscript 斜杠命令、酒馆第三方扩展 | 暂不支持，相关数据会保留 |
| Text Completion、群聊、`.charx` 格式 | 暂不支持 |

## 常见问题

**安装时提示「Windows 已保护你的电脑」**

Hearth 暂时没有数字签名。点「更多信息」，再点「仍要运行」。之后软件内的自动更新不会再出现这个提示。

**关闭窗口后找不到 Hearth**

Hearth 在屏幕右下角的通知区域。Windows 11 可能把图标收在任务栏的 `^` 里。也可以从开始菜单再打开一次 Hearth。

**Hearth 自己重启了一下**

这是在安装更新。新版本下载好后，Hearth 会在你没有使用的时候自动重启：窗口在后台超过 1 分钟，或者 3 分钟没有操作。正在生成回复或者有没保存的修改时不会重启。重启后会提示「已更新到」哪个版本。

**更新下载很慢**

更新文件放在 GitHub 上。在代理工具里开启「系统代理」后，下载会经过代理。除了 Electron 内核升级的版本，平常的更新通常只需要下载 1 MB 以内。

**接口报错**

先在「设置 → 模型连接」里点「测试连接」。报错信息会说明原因，例如密钥不对、地址不对或连不上。
