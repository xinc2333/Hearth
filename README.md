# Hearth

轻量的桌面角色扮演对话工具，兼容 SillyTavern（酒馆）的角色卡、世界书和预设。

## 功能

- **直接使用酒馆的素材**：导入角色卡（PNG / JSON）、世界书和 Chat Completion 预设，提示词的组装规则与酒馆一致。
- **提示词追踪**：每次发给模型的完整内容都看得到，每一段都标明来源，以及触发了哪些世界书条目、为什么触发。
- **前端卡与 MVU**：消息里的状态栏等界面能正常渲染；MVU 变量按楼层和版本分别保存，切换版本时状态跟着切换。
- **EJS 模板**：兼容 ST-Prompt-Template 的常用写法，例如按剧情阶段载入不同章节。
- **跑团**：行动有掷骰检定，角色（包括你）有属性，角色之间有多条线的态度，爱恨可以并存。数值由程序计算，模型照结果写剧情。第一版适配小猫之神预设。
- **可撤销的编辑**：角色卡、世界书、预设的每次修改都有记录，随时可以撤销。
- **装好就能用**：Windows 安装包，自带运行环境，不用另装 Node.js；有新版本时在软件里提示，点一下就更新。

## 快速开始

### 安装（推荐）

1. 从 [Releases](https://github.com/xinc2333/Hearth/releases) 下载最新的 `Hearth-Setup-X.Y.Z.exe`，双击安装。可以选择安装位置，不需要管理员权限；最后一页可以选择是否创建桌面快捷方式。
2. 装好后，从开始菜单（或桌面快捷方式）打开 Hearth。
3. 点窗口右上角的 × 时，Hearth 不会退出，而是缩到屏幕右下角的通知区域继续运行，正在生成的回复也不会中断。单击那里的 Hearth 图标可以重新打开（Windows 11 可能把它收在任务栏的 `^` 里），再从开始菜单打开一次 Hearth 也能回到窗口；要真正退出，右键点图标，选「退出 Hearth」。

第一次安装时，Windows 可能会提示「Windows 已保护你的电脑」。这是因为 Hearth 还没有数字签名：点「更多信息」，再点「仍要运行」。以后在软件里自动更新，不会再出现这个提示。

### 从解压版迁移

0.4.0 及更早的版本是 zip 压缩包，双击 `Start.bat` 启动。换成安装版时：

1. 先关掉旧版 Hearth 的黑色命令行窗口。
2. 安装新版并打开。第一次打开时会询问要不要导入旧版数据：选「导入旧版数据…」，再选旧版 Hearth 所在的文件夹，也就是放着 `Start.bat` 的那个。
3. 对话、角色卡、预设、设置和 API 密钥都会复制过来，旧文件夹里的文件不动。确认新版一切正常后，可以删掉旧文件夹。

旧版 `Start.local.bat` 里的代理设置不用再填，见下面的「网络代理」。

### 从源码运行

```
git clone https://github.com/xinc2333/Hearth.git
cd Hearth
npm install
npm run build
```

然后运行 `npm run desktop` 打开桌面窗口，或者双击 `Start.bat`（命令行版，需要 [Node.js](https://nodejs.org/) 20 或更高版本，数据放在仓库的 `data/` 里）。

## 使用说明

### 连接模型

第一次打开会进入「设置 → 模型连接」：

- **接口地址**：OpenAI 兼容接口，通常以 `/v1` 结尾，例如 `https://api.deepseek.com/v1` 或各类中转地址。
- **API 密钥**：只保存在本机数据目录的 `secrets.json` 里。
- **模型**：点「模型」一栏，会自动列出这个接口的全部模型，可以搜索，选中就生效。列表里没有的模型，也可以直接输入名字。

### 网络代理（可选）

Hearth 和浏览器一样使用系统代理：V2Ray、Clash 这类工具打开「系统代理」后，Hearth 的请求就会经过它，不需要另外设置。

- 如果不想改系统代理，可以设置环境变量 `HTTPS_PROXY`（例如 `http://127.0.0.1:10808`），Hearth 启动时会使用它。
- 用 `Start.bat` 从源码运行时：把 `Start.local.example.bat` 复制一份，改名为 `Start.local.bat`，再按里面的示例填写代理地址。这种方式需要 Node.js 24.5 或更高版本。

### 导入

把文件拖进窗口，或点左上角的「导入」：

| 文件 | 导入为 |
| --- | --- |
| 角色卡 PNG / JSON（V1 – V3） | 角色；卡里自带的世界书会一起导入并自动绑定 |
| 酒馆世界书 JSON | 世界书，在角色的「世界书」面板里绑定 |
| 酒馆 Chat Completion 预设 JSON | 预设，导入后自动设为当前预设 |

导入的原始文件会备份在数据目录的 `imports/` 里。

### 预设

预设是全局的：所有角色和对话共用同一个当前预设。在「设置 → 预设」里管理；点聊天顶部的「预设：…」也能直接打开。

- **导入预设**：选择酒馆导出的 `.json` 文件。
- **切换**：从下拉框选择预设，点「设为当前预设」。
- **开关条目**：和酒馆一样，立即生效；点开条目可以查看和编辑内容。
- **分组和单选**：Meowssiah 这类带菜单标记的预设，`----角色控制----` 这样的分隔条目会显示成分组标题；标了「单选」的同组条目只能开一个。

### 界面

- **左侧**：角色和对话列表。悬停在对话上可以删除；按 `Ctrl+B` 或点右上角的按钮可以收起侧栏。
- **中间**：对话区。悬停在消息上可以复制、编辑、删除，或者从某条回复创建分支（新对话，原对话不变）；最后一条回复可以切换版本、重新生成或继续写。
- **面板**：点右上角的「面板」（或按 `Ctrl+I`）打开，拖动左边缘可以调整宽度：

| 标签 | 内容 |
| --- | --- |
| 提示词 | 上一次（或下一次）请求的完整内容 |
| 变量 | MVU 状态、对话变量和最近一轮的变化 |
| 角色卡 / 世界书 | 直接编辑；把鼠标移到长文本框上，点右上角的按钮可以放大编辑 |
| 预设 | 当前预设的条目开关 |
| 历史 | 所有修改，可以逐条撤销 |

### 让 AI 改卡

把输入框左下角从「剧情」切换到「编辑」，然后直接说想怎么改，例如「把简珣祎的年龄改成二十八岁」「根据刚才的剧情，给书摊老板加一个世界书条目」。

- AI 会先说明打算怎么改，然后直接保存。消息下面会列出每一处改动：点「查看改动」可以看前后对照，点「撤销」会撤销这一轮的全部修改。
- 只改你要求的部分，其余文字一个字都不动；导出给酒馆也照常使用。
- 变量初始化、变量规则、带模板代码的条目默认只读，避免改坏 MVU 和章节控制；需要时在世界书条目里打开「允许 AI 修改」。和其他角色共用的世界书也是只读的。
- 编辑模式里的对话不会混进剧情。切回「剧情」就继续故事。

### 跑团

让剧情有掷骰检定、角色属性和角色之间的态度。数值只是让剧情更真实的依据，一切从主角的视角出发。详细规则见 [docs/tabletop.md](docs/tabletop.md)。

**准备（每张卡一次）**

1. 预设用小猫之神（Meowssiah）。打开面板的「跑团」页，点「加到当前预设」，预设末尾会多出三条「🎲」条目（裁定说明、叙述与结算说明、检定绝对通过说明），可以在预设里查看和修改。
2. 切换到「编辑」模式，点输入框下方的「数据化适配」。AI 会通读卡片和世界书，给主角和重要角色打分（普通成年男性 = 100），写出他们之间的初始态度，每个数值都附原文依据。可以接着说「林晚的力量太高了」让它调整，也可以一键撤销。

**每一轮**

1. **裁定**：模型先判断你这一轮的行动里哪些事结果说不准，写好大成功、成功、失败、大失败四种结果，Hearth 掷骰，选出掷中的那一种。有先后依赖的检定可以分几次掷。
2. **叙述与结算**：模型按掷中的结果写正文，末尾附一个隐藏的结算块，Hearth 按规则更新态度、状态等数值。

- 回复上方显示这一轮的检定，点开可以看理由和计算过程。主角察觉不到的「暗骰」默认收起。
- 换一版回复只重写正文，骰子不变；改了自己的消息再重新生成，会重新裁定。
- 输入框旁的「检定绝对通过」：这一轮不掷骰，主角的行动全部顺利，发出后自动关掉。猫神的「聊天」模式不会掷骰。
- 「跑团」页按主角视角显示数据：NPC 只显示大致水平，他们心里的态度默认藏着，点「揭开」才显示。也可以直接编辑数值。
- 每轮多一次裁定请求，正文出来前会多等几秒。两次请求的前面部分一模一样，接口支持缓存时第二次更快。

### 插件

「设置 → 插件」里可以开关插件、检查更新，或者粘贴 GitHub 链接安装新插件。Hearth 自带三个插件：

| 插件 | 兼容 | 作用 |
| --- | --- | --- |
| 提示词模板 | [ST-Prompt-Template](https://github.com/zonde306/ST-Prompt-Template) | 运行预设、角色卡和世界书里的 EJS 模板 |
| 酒馆助手 | [JS-Slash-Runner](https://github.com/N0VI028/JS-Slash-Runner) | 消息里的状态栏等前端界面、MVU 变量、SPreset 类预设（如 Meowssiah） |
| 跑团 | — | 掷骰检定、角色属性和态度，编辑模式里的「数据化适配」 |

插件会自动更新，每个插件都可以单独关掉自动更新。关闭某个插件后，卡片和预设里对应的内容原样保存，只是不再处理。关闭「跑团」时，请同时关掉预设里的三条「🎲」条目，否则它们会被当成普通条目发给模型。

### 阅读

点聊天窗口右上角的「Aa」可以调整正文的字体、字号、行距、栏宽，以及段首缩进、两端对齐和对话着色。「自定义」字体可以填电脑上已安装的任何字体名（例如霞鹜文楷）。

回复生成时，画面默认停在回复的开头，方便从第一行读起；想一直跟着最新文字，可以在阅读设置里打开「生成时自动滚到最新文字」。

## 兼容情况

| 内容 | 状态 |
| --- | --- |
| 角色卡字段、备选开场白、角色备注（深度提示） | 支持 |
| 预设条目顺序、开关、注入深度和角色，主提示词 / 后置指令覆盖 | 支持，与酒馆的组装规则一致 |
| 世界书：关键词逻辑、扫描深度、递归、分组、概率、预算、sticky / cooldown / delay、八种插入位置 | 支持 |
| 宏：`{{char}}`、`{{user}}`、嵌套宏、变量宏、`{{random}}`、`{{roll}}`、时间、注释等 | 支持常用宏 |
| 正则脚本：作用位置、仅提示词 / 仅显示、深度限制 | 支持 |
| 前端卡（消息里的 HTML 界面、状态栏） | 在沙箱中渲染，提供酒馆助手常用接口和 jQuery、lodash |
| MVU（MagVarUpdate） | 支持初始化、JSONPatch 和 `_.set` 更新，模型漏写时自动补全 |
| EJS 提示词模板（ST-Prompt-Template） | 支持 `getvar`、`setvar`、`getwi`、`print` 等常用接口 |
| Meowssiah / SPreset 类预设 | 在沙箱中运行预设自带的请求脚本（Stage 1），发出的请求和酒馆里一致；小猫之神控制台（剧场 / 聊天、深度思考、纸条）在输入框里 |
| 酒馆助手脚本、STscript 斜杠命令、酒馆第三方扩展 | 尚未支持（数据会保留） |
| Text Completion / instruct 模板、群聊、`.charx` | 尚未支持 |

## 数据与安全

- 所有数据都在数据目录里，每个角色、世界书、预设、对话各是一个 JSON 文件；安装的插件和插件更新在其中的 `plugins/`。备份时复制整个目录即可。
  - 安装版的数据目录是 `%APPDATA%\Hearth\data`：在资源管理器的地址栏输入 `%APPDATA%\Hearth` 就能打开。更新和卸载 Hearth 都不会删除它。
  - 从源码运行时，数据目录是仓库里的 `data/`。
- 运行记录在 `%APPDATA%\Hearth\logs\hearth.log`，遇到问题时可以附上它。
- 服务只监听本机（`127.0.0.1`），并拒绝来自其他网站的请求。
- 角色卡和预设里的代码在沙箱中运行：EJS 模板运行在 QuickJS（WebAssembly）里，访问不到文件和网络；消息里的 HTML 界面运行在隔离的 iframe 里。
- 预设自带的请求脚本（如 SPreset 的 Stage 1）在沙箱中运行，访问不到网络。预设脚本引用的远程代码不会下载或执行，SPreset 的日志上传也没有实现。

## 开发

### 目录结构

```
src/core/     数据模型、提示词组装、世界书、宏、正则、MVU、酒馆格式导入（不依赖界面，可单独测试）
src/server/   本地服务：存储、模型接口、生成流程、插件、内置适配
src/web/      界面（React）
src/desktop/  桌面版（Electron）：窗口、旧数据导入、自动更新
src/plugins/  内置插件的源码（构建到 plugins/）
resources/    图标和安装包设置
tests/        测试
docs/         设计说明
plugins/      内置插件（构建结果，也是插件的更新来源）
```

### 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run build` | 构建界面、服务、桌面版和内置插件，输出到 `dist/` 和 `plugins/` |
| `npm run desktop` | 用构建结果打开桌面窗口（按 `F12` 打开开发者工具） |
| `npm run dist` | 构建并打包 Windows 安装包，输出到 `release/` |
| `npm test` | 运行测试 |
| `npm run typecheck` | 类型检查 |
| `npm run dev:server` / `npm run dev:web` | 开发模式 |

设计说明和插件接口见 [docs/architecture.md](docs/architecture.md)，提交与发布规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 版本与更新

版本号遵循[语义化版本](https://semver.org/lang/zh-CN/)，每个版本的变化记录在 [CHANGELOG.md](CHANGELOG.md)。当前版本号可以在「设置 → 阅读与外观」里看到。

安装版会自己检查更新：打开后十几秒检查一次，之后每 6 小时检查一次。

- 发现新版本时在后台下载，通常只下载有变化的部分。下载好后，窗口顶部会提示「现在重启更新」，点一下，Hearth 会关闭、安装，然后自动重新打开。
- 不点也没关系，下次退出 Hearth 时会自动装好。
- 「设置 → 阅读与外观 → 版本」里可以手动检查更新。
- 插件有自己的自动更新，不受影响。

0.4.0 及更早的解压版不会自动更新，换成安装版的方法见[从解压版迁移](#从解压版迁移)。
